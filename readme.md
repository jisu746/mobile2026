## 실행 방법

MySQL을 실행한 뒤 명령 프롬프트 두 개에서 각각 실행합니다. 프로젝트 위치가 다르면 경로를 변경

### 프론트엔드

```bat
cd /d C:\mobile2026\mobile
npm ci
npx expo start --web
```

`npm ci`는 최초 실행 또는 의존성 변경 시 실행

### 백엔드

```bat
cd /d C:\mobile2026\backend
gradlew.bat bootRun
```

- Java 21, Node.js, MySQL 설치 필요
- `smartstore` 데이터베이스 생성 필요
- DB 접속 정보는 `backend/src/main/resources/application.properties`에서 설정
- 실행 중에는 서버와 프론트엔드 명령 프롬프트를 열어두기

- 실제 DB 비밀번호가 들어 있는 설정 파일을 그대로 공유하지 않도록 정리
- 이미 Git이 추적하는 비밀번호는 `.gitignore` 추가만으로 해결되지 않으므로 별도 처리
- DB 접속 정보의 환경변수 분리
- `auto-approve=false`, `any-qr=false` 유지
- 샘플 상품이 필요 없어지면 `seed-products=false`로 변경
- 서버 CORS 허용 주소 제한
- 로컬 테스트 계정·상품·메모 등 데이터 정리
- 팀원이 같은 파일을 수정했다면 덮어쓰기 전에 비교·병합

## 백업 및 검증

- 전체 소스 백업 ZIP 생성함.
- 팀 공유용 변경 파일 ZIP 생성함.
- 공유 파일에서 실제 DB 비밀번호 제외함.
- DB 데이터는 ZIP에 포함하지 않으며 별도 백업이 필요함.
- 앱 TypeScript 검사 통과함.
- 직원 관리 저장소 모의 테스트 7개, 일정 저장소 모의 테스트 8개 통과함.
- Java 단위 테스트 파일을 포함했으나 별도 실행 확인이 필요함.
