# 주휴·야간·휴일 자동 계산 (2026-11-25)

## 적용 범위와 입력

성인 시급제·일반 근로시간제를 대상으로 합니다. 월급제, 탄력/선택근로, 감시단속 승인, 특수한 통상임금 구성 등은 이 계산으로 확정하지 않습니다. 사장님이 적용 범위를 확인해야 반영할 수 있습니다.

- 직원별·급여월별로 상시근로자 5인 이상/미만, 단시간 근로 여부, 1주 시작 요일을 저장합니다. 앱 계정 수로 사업장 규모를 추정하지 않습니다.
- 기본급과 근로 가산은 기존 근무별 보존 시급으로 계산합니다. 주휴/유급휴일은 해당 지급일에 적용할 통상시급을 이력과 대조해 입력합니다. 기본 시급 외 정기 수당 등이 통상임금에 포함되는 경우 별도 검토가 필요합니다.
- 실제 무급 휴게 구간을 입력하고 확인합니다. 비어 있는 구간도 '실제 휴게 없음' 확인이 필요하며 법정 최소 휴게를 임의 차감하지 않습니다.
- 주별로 최대 4주의 약정시간 합계, 산정 주 수, 동일 기간 통상근로자 약정 근무일수, 개근/실제 출근일/근로관계 유지 여부를 확인합니다. 약정시간이 일정하지 않은 경우 실제 약정 기록에 따라 입력합니다. 지각·조퇴·유급휴가를 임의로 결근 처리하지 않습니다.
- 주휴일과 공휴일·대체공휴일·근로자의 날·약정휴일 및 휴일대체는 대상 직원별로 확인합니다. 휴일 달력을 자동 조회하는 기능은 포함하지 않습니다. 주휴 외 휴일에는 가산 적용 여부와 별도 유급 임금 시간을 입력합니다. 주휴일과 다른 유급휴일이 겹치면 중복 유급 지급을 확인하도록 반영을 막습니다.
- 단시간 근로자는 당일/해당 주 약정 실근로시간을 추가 입력하여 법정 8시간/40시간 이내의 약정 초과분도 계산합니다.

## 계산

1. 주휴: 산정 기간 약정시간 ÷ 산정 주 수가 **15시간 이상**이고 개근 등 확인 조건을 충족해야 합니다. 단시간 근로자의 지급 시간은 `산정 기간 약정시간 합계 ÷ 같은 기간 통상근로자 근무일수` (최대 8시간). 통상근로자는 확인한 1일 정상 근로시간 (최대 8시간)을 사용합니다. 지급 시간 × 확인한 통상시급입니다.
2. 야간: 실제 근로 중 **22:00~06:00** 구간에 **50% 추가**합니다.
3. 휴일: 확인한 적용 휴일의 실제 근로 **8시간 이내는 50%, 초과분은 100% 추가**합니다. 같은 날짜의 복수 근무는 합산합니다.
4. 일반 연장: 일 8시간/주 40시간 초과분을 50% 가산하며 일·주 초과를 중복 계산하지 않습니다. 단시간 약정 초과도 가산합니다. 휴일 구간은 휴일 가산으로 계산하여 연장 가산을 이중 청구하지 않습니다. 야간은 별도로 합산합니다.
5. 상시 5인 미만은 법정 연장/야간/휴일 가산을 자동 적용하지 않습니다. 별도 지급 약정이 있으면 명시적으로 동일 가산 적용을 선택할 수 있습니다. 주휴는 사업장 5인 기준과 분리합니다.
6. 유급휴일 임금은 해당 날 근로에 대한 기본급·가산과 별도 항목입니다. 휴게 차감도 별도 정정 항목으로 남깁니다. 원래 근무별 시급·기본급 기록을 덮어쓰지 않습니다.
7. 시간은 초 단위로 경계를 나누며 금액은 항목별 합계 후 원 단위 반올림합니다. 주휴/유급휴일은 지급일이 속한 월, 근로 가산/휴게 차감은 기존 명세와 일치하도록 출근일이 속한 월에 반영합니다. 월초 주간 합산을 위해 직전 달 근무도 조회합니다.

## 저장·권한·감사

`GET/PUT /api/stores/{storeId}/staff/{memberId}/payroll/automatic?month=YYYY-MM`

`POST /api/stores/{storeId}/staff/{memberId}/payroll/automatic/apply?month=YYYY-MM`

사장님만 설정·미리보기·반영이 가능합니다. 직원은 기존 본인 명세에서 반영 결과를 확인합니다. 설정 revision과 계산 해시로 동시 수정/오래된 미리보기를 방지합니다. 재반영은 이전 자동 항목을 취소 이력으로 보존하고 교체합니다. 동일 해시 재시도는 중복 지급하지 않습니다. 직접 입력한 같은 수당과 중복 반영을 막고, 자동 항목의 개별 삭제는 차단합니다. 출퇴근/시급/설정이 바뀌면 재계산 전 명세 확정을 차단합니다. 확정 후에는 변경할 수 없습니다.
