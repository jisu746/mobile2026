- 로그아웃·비밀번호 변경·기기 계정 변경 후 이전 계정 푸시 차단

## 검사 데이터 분리

서버 검사는 테스트 전용 H2 임시 DB를 사용한다. 테스트 설정은 `src/test/resources/application.properties`에 있고, 운영 스케줄러와 실제 푸시 전송은 꺼져 있다. 실제 매장의 DB를 테스트용으로 사용하지 않는다.

## 다시 실행

백엔드 폴더:

```bat
gradlew.bat test bootJar
```

모바일 폴더:

```bat
npx tsc --noEmit
npx expo export --platform all --max-workers 2
```

## 아직 검증하지 않은 실제 환경

실제 Google Vision 응답 품질, FCM/APNs 수신, 운영 HTTPS 서버, 실제 Android/iPhone 하드웨어, 스토어 제출은 별도 환경이 필요하다. 수당·공제의 법적 적용 여부는 이 자동 검사로 판단하지 않는다. 코드/번들 검사를 실제 기기 전체 기능 검증으로 표현하지 않는다.

개발용 APK는 개발 서버에 연결하는 앱이다. 독립 배포용 APK나 실제 기기 기능 전체 검증을 완료한 릴리스가 아니다. Windows 네이티브 빌드의 경로 길이 제한은 짧은 CMake 작업 경로와 객체 파일 경로 제한 설정으로 해결했다.
